## ບັນຊີລະດັບແຂວງ

ລະດັບ `province` (ບໍ່ມີເມືອງ) — ເບິ່ງທະບຽນທັງໝົດໃນແຂວງ; ມີແຕ່ບົດບາດ `admin` ເທົ່ານັ້ນທີ່ຈັດການບັນຊີໄດ້; ຜູ້ໃດກໍຕາມທີ່ຢູ່ລະດັບແຂວງຈະບໍ່ສາມາດເພີ່ມ/ແກ້ທະບຽນ (ການບັນທຶກຂໍ້ມູນເປັນໜ້າທີ່ຂອງລະດັບເມືອງ).

## ໜ້າທຳອິດສຳລັບຜູ້ຈັດການ (manager)

ບັນຊີ `manager` ພໍເຂົ້າສູ່ລະບົບຈະໄປໜ້າ **ພາບລວມ (Overview)** ແບບເບິ່ງຢ່າງດຽວ (`/admin/monitor.php`) — ຄວາມຄືບໜ້າການເກັບກຳ, ສະຖານະການເຊັນສະລິບ, ເນື້ອທີ່ດິນ ແລະ ຍອດຄ້າງຊຳລະ, ໂດຍຂອບເຂດຕາມເມືອງຂອງຜູ້ຈັດການ (ຫຼື ທົ່ວແຂວງຖ້າເປັນລະດັບແຂວງ). ຫຼັງຈາກນັ້ນ ຜູ້ຈັດການເຫັນ **ເມນູຄົບຄືກັບເຈົ້າໜ້າທີ່** (ພາບລວມ, ໜ້າຫຼັກ, ຂໍ້ມູນພື້ນຖານ, ປ້ອນຂໍ້ມູນໃບຕາດິນ, ລາຍການໃບຕາດິນ, ພາສີທີ່ດິນ, ກວດສອບການຊຳລະ, ນຳເຂົ້າລາຍການທະນາຄານ, ລາຍງານ, ຜູ້ໃຊ້) ແຕ່ **ອ່ານຢ່າງດຽວ**: ປຸ່ມຂຽນຖືກເຊື່ອງ, ໜ້າຈະປະຕິເສດ POST ຂອງ manager, ແລະ `api/v1` ປະຕິເສດການຂຽນທຸກຄັ້ງ. ການບັນທຶກຂໍ້ມູນຍັງເປັນໜ້າທີ່ຂອງບັນຊີ admin/officer ລະດັບເມືອງ.

## ເພີ່ມພະນັກງານເພີ່ມເຕີມ

- ຜູ້ດູແລລະດັບເມືອງ: ໜ້າ Admin → ຜູ້ໃຊ້ງານ (Users) → ສ້າງບັນຊີພະນັກງານໃໝ່ (ເມືອງຂອງຕົນເທົ່ານັ້ນ).
- ຜູ້ດູແລລະດັບແຂວງ: ໜ້າດຽວກັນ, ເລືອກເມືອງໃດຫຼືລະດັບແຂວງກໍໄດ້.
- ຫຼື ລຳໜົງ `sql/migrations/003_seed_staff_accounts.sql` ໃໝ່ເທິງເຊີເວີ (ເຮັດຊ້ຳໄດ້ໂດຍບໍ່ເກີດຜົນເສຍ — `ON CONFLICT DO NOTHING`).

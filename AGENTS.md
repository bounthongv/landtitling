# Land Title Management System — AGENTS.md

## What is this?
Prototype web app for a land title registry (Lao language). Demonstrates:
- Parcel/land record management
- Right holder tracking
- Transfer and mortgage workflows
- GIS map integration
- QR code on title documents

## Key Files
| File | Purpose |
|------|---------|
| `prototype/index.html` | Single-page prototype (HTML/CSS/JS) with mock data |
| `prototype/build/gen_qr.py` | Generates QR codes for title parcels |
| `docs/LandTitling.md` | System requirements (Lao/English) |
| `docs/LandTitling.docx` | Original specification |

## How to Run
1. Open `prototype/index.html` in a browser
2. Demo login: `officer` / `demo1234` (any input works)

## Architecture Notes
- Pure HTML/CSS/JS — no build system, no framework
- Mock data embedded in JS (PARCELS, PERSONS, DISTRICTS constants)
- All views rendered via JavaScript tab switching
- QR codes are base64-encoded PNGs (generated by `gen_qr.py`)

## Prototype Data
- 6 parcels across 6 districts in Savannakhet
- Each parcel has: code, title number, holder, area, usage type, mortgage status, history
- Districts: Kaysone, Outhoumphone, Phalanxay, Chonnabouli, Songkhone, Champhone

## Features Shown
- Dashboard with statistics
- Search parcels by code/owner/village
- Add new parcel / import from legacy (mock UI)
- Transfer workflow (5-step: Request → Verify → Approve → Update → History)
- Mortgage registration/release
- Interactive map (click pins to view parcel details)
- Reports by land use, transfers, mortgages

## Important
- This is **demo-only** — no backend, no database
- "Save" and "Import" buttons show mock progress only
- For real implementation: need backend, database, authentication, GIS server
